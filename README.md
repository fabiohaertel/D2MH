# D2MH - Diablo 2 Map Assist

A map assist tool for Diablo 2 Resurrected. It was originally built using code from several different GitHub repositories. Over time, I started using AI to add new features, eventually turning it into a full-featured map overlay.

**Features:**

- Reveals the entire map
- Displays monsters and their resistances
- Monitors drops based on the items configured in `config.py`
- Provides audio alerts
- Allows you to move the overlay using the arrow keys
- Press `Shift + Tab` to show or hide the overlay

**Warning:**

Use it online at your own risk.
